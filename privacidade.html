Política de privacidade

Última atualização: 5 de novembro de 2026

Esta política explica como o aplicativo ALBERT (ALBERT Desktop para Windows) usa os dados de uma conta Google. O ALBERT é um projeto pessoal de Sebastian Cruz Aiello, usado por ele mesmo no próprio computador.

1. Quais dados do Google o ALBERT acessa

Só depois que o usuário entra com a conta Google e autoriza, o ALBERT pede estes acessos:

  • Identificação básica (openid e e-mail): para saber qual conta está conectada.
  • Google Agenda (https://www.googleapis.com/auth/calendar): ler, procurar, criar e alterar compromissos.
  • Gmail (https://www.googleapis.com/auth/gmail.modify): ler e procurar e-mails, marcar como lidos, usar marcadores e criar rascunhos. Enviar um e-mail só acontece depois de aprovação explícita do usuário no app.

2. Como esses dados são usados

Os dados são usados apenas para atender ao que o próprio usuário pede ao ALBERT, por exemplo "o que tenho amanhã?", "resuma os e-mails de hoje" ou "marque reunião às 15h". O ALBERT não usa esses dados para publicidade, não cria perfis de marketing e não os vende nem os empresta a ninguém.

3. Onde os dados ficam

  • O login usa OAuth 2.0 com PKCE. A senha do Google nunca passa pelo ALBERT.
  • Os tokens de acesso ficam guardados no Gerenciador de Credenciais do Windows, no próprio computador do usuário.
  • E-mails e compromissos são buscados diretamente do Google para o computador do usuário quando ele pede, e não são copiados para nenhum banco de dados do ALBERT.
  • Quando o usuário pede para o ALBERT resumir ou responder sobre um e-mail ou compromisso, o trecho necessário entra na conversa e é enviado ao servidor pessoal do ALBERT e ao serviço de IA da Anthropic (Claude API), apenas para gerar a resposta. A Anthropic não usa dados enviados pela API para treinar modelos, conforme as condições comerciais dela.
  • O histórico das conversas fica salvo no computador do usuário, que pode apagá-lo pelo próprio app.

4. Compartilhamento

Os dados do Google não são compartilhados com terceiros, exceto o envio pontual ao serviço de IA descrito acima, que é necessário para o ALBERT funcionar. Nenhuma pessoa lê os seus e-mails ou compromissos, a não ser você mesmo.

5. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Os dados do Google não são usados para treinar modelos de inteligência artificial genéricos.

6. Como retirar o acesso e apagar dados

  • No ALBERT, use a opção para sair da conta Google. Os tokens são apagados do Gerenciador de Credenciais do Windows.
  • A qualquer momento, é possível retirar o acesso em myaccount.google.com/permissions.
  • Para pedir a exclusão de qualquer dado, escreva para o contato abaixo.
